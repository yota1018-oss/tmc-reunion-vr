# TMC同窓会VR

第3回TMC同窓会〜異業種交流会〜（2027年2月27日（土）／東京経済大学 2号館・葵テラスEAST 1階）の
**会場・動線・タイムラインをVRで事前体験・リハーサル**するためのWebアプリです。

- Meta Quest のブラウザ、PC、スマホで **URLを開くだけ** で動きます（インストール不要）
- 合言葉を知っている人どうしで **同じ空間に入り、テキストチャット** ができます
- 時刻を進めると、その時間帯の **人の流れ・スクリーンのスライド・行き先の案内** が切り替わります

## 機能

| 機能 | 内容 |
| --- | --- |
| 動線ガイド | 床のオレンジの矢印と光の柱で「今の時間に向かう場所」を案内。学年によってセミナー教室A/Bを出し分け |
| タイムライン再生 | 12:30〜18:30を ×30 / ×60 / ×180 で再生。時間帯ごとに想定参加者（半透明の人影）が各部屋へ移動 |
| スクリーン | メイン会場・セミナー教室・葵テラスのスクリーンにスライドを表示。PowerPointをPNG書き出しして差し替え可能 |
| 名札 | 名前・区分（色分け）・業界・所属を頭上と胸に表示。未成年は赤いリボン |
| チャット | 定型文ボタン＋自由入力。頭上に吹き出しが出る。履歴はサーバーに保存 |
| 運営モード | 区分「運営」で入ると運営向けメモが表示され、「全員の時間・スライドを操作する」で全員の時計とスライドを同期できる（リハーサル用） |
| 見取り図 | 右下のミニマップに自分・他の参加者・目的地を表示 |

## 使い方

1. URLを開き、名前・区分・業界を入力
2. **みんなと入場する**：合言葉を入力（案内メールに記載）／**ひとりで下見する**：オフラインで会場だけ見る
3. 操作
   - PC：WASD・矢印キーで移動、ドラッグで見回す、Shiftで速く歩く
   - スマホ：左下のスティックで移動、スワイプで見回す
   - Meta Quest：右下の「ENTER VR」→ 左スティックで移動、右スティックで30°ずつ回転。左手のパネルを右手のトリガーで押す

合言葉は URL に `?pass=合言葉` を付けると自動入力されます（案内メールに載せるときに便利）。

## 仮になっている部分（要差し替え）

すべて `src/config.js` にまとまっています。

- **会場レイアウト**：`ZONES` の `rect`（部屋の範囲）と `door`（出入口）を、会場の写真・図面に合わせて修正してください。単位はメートルです
- **タイムライン**：`SCHEDULE` の時刻・内容・行き先・運営メモ
- **スライド**：`slides` に `{ title, sub }` か `{ image: 'slides/ファイル名.png' }` を指定。画像は `public/slides/` に置く
- **想定参加人数**：`EXPECTED_PEOPLE`

## 合言葉の変更

Supabase のダッシュボード → SQL Editor で次を実行します（仮の合言葉は `tmc2027`）。

```sql
update public.app_secret
set pass_hash = encode(sha256(convert_to('新しい合言葉', 'UTF8')), 'hex')
where id = 1;
```

合言葉を変えると、チャットのチャンネルも自動的に別のものになります。

## 開発・公開

```bash
npm install
```

```bash
npm run dev
```

`main` ブランチに push すると GitHub Actions で GitHub Pages に公開されます
（リポジトリの Settings → Pages → Source を **GitHub Actions** にしてください）。
WebXR は https でしか動かないため、Quest で試すときは公開後の URL を使ってください。

## 構成

- `src/config.js` … 会場・タイムライン・区分などの設定
- `src/venue.js` … 会場の3Dモデル・スクリーン・当たり判定
- `src/crowd.js` … 想定参加者の人影
- `src/guide.js` … 動線ガイド（矢印）
- `src/avatar.js` … アバター・名札・吹き出し
- `src/net.js` … Supabase Realtime による同時接続・チャット
- `src/xr.js` … VRコントローラー・手元パネル
- `supabase/migrations/` … データベース（合言葉チェック・チャット保存）

サーバーは Supabase プロジェクト `tmc-reunion-vr`（東京リージョン）です。
テーブルには直接アクセスできず、合言葉を確認する関数経由でのみチャットの読み書きができます。
